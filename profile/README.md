## 关于我们

北京大学金融科技协会成立于 2017 年，是一个致力于运用前沿科技探索金融领域的学术性社团。

这里汇集协会的技术内培、竞赛复现和研究实践。我们希望将学习中的代码、实验和经验整理成可以继续使用的材料，让每一届成员都能在已有积累上开展新的探索。

我们的实践围绕三个方向展开：

- **量化研究与金融数据**：探索数据、构建因子，理解金融时序与模型评估。
- **机器学习与竞赛复现**：通过具体赛题学习特征工程、模型训练与实验分析。
- **区块链与金融科技**：通过模拟与代码实验研究交易机制及相关技术问题。

## 项目与实践

### 竞赛复现与量化研究

- **[2024 Competition Reproduction Training](https://github.com/PKUAFT/AFT-2024-Competition-Reproduction-Training)**：围绕 Kaggle Optiver 2023 Trading at Close 赛题，整理 EDA、特征工程与模型训练的内培代码和实验材料。
- **[2025 Competition Reproduction Training](https://github.com/PKUAFT/AFT-2025-Competition-Reproduction-Training)**：金融时序预测项目，包含特征工程、多种模型架构与滚动窗口训练的探索。

### 学习资源与协会作品

- **[Festive Greetings](https://github.com/PKUAFT/AFT-Festive-Greetings)**：使用 JavaScript、HTML、Python 等语言创作的节日祝福作品。

## 参与贡献

欢迎从一个具体问题开始参与：

1. **选择项目**：阅读 README，了解项目目标、环境要求和已有材料。
2. **提出问题**：在对应仓库提交 Issue，说明遇到的困难、复现步骤或改进想法。
3. **提交改进**：通过 Pull Request 贡献代码、文档、实验记录或学习笔记，并说明修改内容与验证方式。
4. **留下可接续的记录**：记录数据来源、代码版本、参数和结果，让后续成员能够理解并继续研究。

文档纠错、安装步骤补充、一个小实验或一段清楚的解释，都是有价值的贡献。

## 使用说明

各项目的环境、数据获取方式、完成程度和许可证以对应仓库的说明为准。涉及外部数据与上游代码时，请遵守其使用条款并保留来源说明。

这些材料用于学习与研究；模型实验、竞赛复现和模拟结果的适用范围取决于具体数据与评估条件。
